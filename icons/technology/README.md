# Technology logo sources

These assets identify technologies used by Clustr Market. They are not partnership badges or endorsements.

- `openai.svg`: unmodified black wordmark from OpenAI's official [2025 logo package](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), file `OpenAI-logos(new)/SVGs/OpenAI-black-wordmark.svg`. Used for the OpenAI SDK credit. OpenAI owns its marks; see its [brand guidelines](https://openai.com/brand/).
- `deepseek.svg`: official header wordmark from [DeepSeek's website](https://www.deepseek.com/), retrieved 8 November 2026. An SVG namespace was added for standalone rendering; paths, colors and proportions are unchanged. DeepSeek owns its marks.
- `javascript.svg`: the [JavaScript community logo](https://github.com/voodootikigod/logo.js/blob/master/js.svg), by Christopher Williams and Manuel Strehl. MIT license and copyright notice are preserved inside the file.

Logos are stored locally so viewing these credits does not contact third-party logo hosts. OpenAI's SDK is used with DeepSeek's API; this is not a claim that current reports run on an OpenAI model.

## Monochrome footer marks

- `deepseek-mark.svg`: the whale group and its clip from the official wordmark above, with the canvas restricted to the symbol. No traced bitmap or altered path geometry.
- `openai-mark.svg`: unmodified `OpenAI-black-monoblossom.svg` from the same official 2025 package. CSS scales away the empty outer artboard while preserving the symbol's proportions.
- `javascript-mark.svg`: a one-ink version of the licensed community logo; the original J/S outlines become transparent cutouts in the square. The MIT notice is retained.

Footer CSS uses these local SVGs as alpha masks filled with `currentColor`, so all visible ink follows the active theme and link hover color. Brand names remain visible link text; decorative marks are hidden from screen readers.
